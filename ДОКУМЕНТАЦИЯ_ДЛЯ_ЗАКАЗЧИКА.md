# Программа лояльности - Инструкция для заказчика

## Что это за сайт?
Веб-сайт для управления бонусной программой. Клиенты получают бонусы за покупки, кассиры начисляют/списывают бонусы через приложение.

## Как пользоваться

### 1. Вход в систему
| Email | Пароль | Роль |
|---|---|---|
| admin@loyalty.local | admin123 | Администратор |
| cashier@loyalty.local | cashier123 | Кассир |

**Администратор** может:
- Список всех клиентов
- Добавлять/редактировать/удалять клиентов
- Просматривать не подтвержденных клиентов
- Настраивать систему

**Кассир** может:
- Список клиентов
- Начислять и списывать бонусы
- Сканировать QR-коды клиентов

### 2. Привязка клиента
**Важно:** Клиент появляется в списке только после подтверждения в Telegram!

**Процесс:**
1. Администратор добавляет клиента (ФИО + телефон)
2. Система создает ссылку для привязки Telegram
3. Администратор отправляет ссылку клиенту
4. Клиент переходит по ссылке в Telegram
5. Бот привязывается и клиент появляется в списке

### 3. Начисление и списание бонусов
1. Кассир открывает страницу "Касса"
2. Сканирует QR-код клиента или вводит ID вручную
3. Выбирает: начислить (+) или списать (-) бонусы
4. Вводит сумму и комментарий (можно пустым)
5. Нажимает кнопку

После операции клиент получает уведомление в Telegram (если привязан).

### 4. Журнал операций
На странице "Журнал операций" можно:
- Просматривать все операции
- Фильтровать по клиенту
- Фильтровать по типу (начисление/списание)
- Фильтровать по датам
- Скачивать в Excel или CSV

## Особенности
- **Темная/светлая тема**: кнопка темы в боковом меню или настройки
- **QR-коды**: клиент скачивает свой QR-код, кассир сканирует для идентификации
- **Telegram уведомления**: клиенту приходят уведомления о начислениях/списаниях со ссылкой на кабинет

## Если что-то не работает
1. Проверьте, что клиент привязал Telegram (должно быть написано "Telegram привязан" на его странице)
2. Проверьте, что бот не заблокирован
3. Свяжитесь с администратору сайта
